# The Epistemic Engine

A Deterministic Structural Auditor for Institutional Discourse

## Overview

The Epistemic Engine is a deterministic, philosophy-grounded auditing system that classifies how institutional text makes its claims rather than what it claims. It implements a six-layer architecture for analyzing structural epistemic properties of institutional discourse.

## Key Features

- **Six-Layer Architecture**: Structural signal extraction, language-game classification, bias-gate detection, authority-laundering identification, learning-posture derivation, and two-axis rhetorical coordinate placement
- **Deterministic Logic**: Fully reproducible outputs based on threshold-based classification
- **Model-Agnostic**: Deployed across OpenAI GPT and Google Gemini platforms
- **Philosophy-Grounded**: Based on frameworks from Kierkegaard, Wittgenstein, Popper, and Argyris

## System Architecture

The engine implements six analytical layers:

1. **Layer 0**: Structural signal extraction (14 signal densities)
2. **Layer 1**: Wittgenstein language-game classification
3. **Layer 2**: Popper bias-gate detection (evasion/ideological/moral framing)
4. **Layer 3**: Authority-laundering identification (scientism/bureaucratic masking/identity laundering)
5. **Layer 4**: Argyris learning-posture derivation
6. **Layer 5**: Two-axis rhetorical coordinate placement
